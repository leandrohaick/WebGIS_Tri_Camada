# WebGIS Ambiental

Mapa interativo das áreas protegidas, corredores ecológicos e pontos ambientais da Região Metropolitana de Belém.

## Uso

Abra o endereço publicado e ative as camadas no painel lateral. Clique nas feições para consultar seus atributos e use **Enquadrar** para centralizar uma camada.
